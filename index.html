Browser File Encryptor

Encrypt or decrypt a file on this device. The file and passphrase never leave your browser. There is no server and no network request.

Encrypt or decrypt a file

Files are held in memory and limited to 50 MiB. Choose a strong passphrase: it is the only secret protecting the file.
